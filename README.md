# To Hilary, With Love
A static birthday archive (HTML/CSS/vanilla JS) for GitHub Pages.

## Add your content
- Photos: put JPGs in `images/memories/` named `adore-1..4.jpg`, `us-1..4.jpg`, `moments-1..4.jpg`, `before-1..4.jpg` (or edit the `collections` array in `js/script.js` to add more, with real captions and dates).
- Music: add your own `music/best-part.mp3`.
- Letters, reasons, final letter: edit the arrays at the top of `js/script.js`. The letters are drafts; rewrite them in your own voice.

## Deploy
Push to GitHub, then Settings > Pages > Deploy from branch `main` / root.
